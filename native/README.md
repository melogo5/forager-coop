# Forager Coop — нативный патч

`version.dll` для папки Forager: передаёт вызовы системной `version.dll` и через MinHook перехватывает
функции игры. Что строим — [docs/coop/SPEC.md](../docs/coop/SPEC.md); как устроен рантайм —
[decompiled/RUNTIME.md](../decompiled/RUNTIME.md).

## Сборка и установка

Нужны Visual Studio Build Tools с C++ (toolset x86).

```powershell
powershell -File native\build.ps1            # -> native\build\version.dll
powershell -File native\build.ps1 -Install   # + копия в папку игры
```

Удаление — стереть `version.dll` из папки игры. Лог — `coop_native_<pid>.log` там же.

## Как играть

Оба игрока в одной сети (LAN, Hamachi или Radmin), у обоих стоит `version.dll`.

1. **Хост:** главное меню → **COOP** → **CREATE** → выбрать сейв или «+» (новый мир). Сервер стартует
   при входе в мир (TCP 7790) и объявляется в сети (UDP 7791).
2. **Гость:** главное меню → **COOP** → ввести имя в поле **NAME** → сервер хоста в списке → **JOIN**.
   Если сервер не виден — ввести IP хоста в поле **IP** → **CONNECT**. Мир хоста загрузится сам
   (во временный слот, который удаляется после выхода). Персонаж гостя хранится у хоста под этим именем.

3. **Выйти из игры:** гость — «Save and exit to menu», потом снова **JOIN** (перезапуск не нужен). Хост —
   «Save and exit to menu»: гость сам вернётся в главное меню; потом оба могут начать заново. Если хост
   пропал (упал, оборвалась связь), гость через несколько секунд тоже вернётся в меню.
4. **Острова** покупает хост (вкладка BUY LAND), остров появляется у обоих. Время суток и погода общие, их ведёт хост. Навыки у каждого игрока свои (очко навыка за каждое повышение общего уровня получают оба); постройки, открытые навыками любого из двоих, может строить и другой.

Брандмауэр Windows при первом запуске спросит разрешение для Forager — его нужно дать.
Что синхронизируется и что нет — [docs/coop/STATUS.md](../docs/coop/STATUS.md).

Для отладки остались параметры запуска: `-coop host 7790` и `-coop join <IP> 7790`.

DLL ставит хуки, только если `Forager.exe` — поддерживаемый билд (PE timestamp `0x60148428`); на другом билде
она просто передаёт вызовы и пишет об этом в лог.

## Состав

- `src/dllmain.cpp` — прокси `version.dll`, запуск
- `src/yyc.h`, `src/yyc.cpp` — рантайм GameMaker: RValue, адреса, вызов встроенных функций, переменные
- `src/menu.cpp` — кнопка COOP в главном меню и экран коопа (список серверов, CREATE, подключение по IP)
- `src/gui.cpp` — рисование и ввод поверх функций GML
- `src/lan.cpp` — поиск серверов: UDP-объявления на широковещательные адреса всех адаптеров
- `src/session.cpp` — сессия: хост/гость, состояние игроков (и инструмент в руках), возрождение вместо game over,
  меню без паузы, конец сессии (выход в меню, пропавший хост)
- `src/puppet.cpp` — напарник как `objPlayer` с отключённой логикой
- `src/world.cpp` — передача мира хоста гостю, временный слот 99 гостя
- `src/sync.cpp` — объекты мира: появление/уничтожение, удары и опыт гостя, добыча сразу в инвентарь,
  постройки гостя, полоски здоровья
- `src/mobs.cpp` — враги: поток позиций с хоста, мир вокруг гостя у хоста не деактивируется
- `src/character.cpp` — персонаж гостя: хранится у хоста по имени (`saveData<N>/coop_guests/`)
- `src/storage.cpp` — общие сундуки и блокировка открытого сундука
- `src/land.cpp` — покупка острова (только хост) с общим зерном генерации
- `src/clock.cpp` — время суток и погода с хоста
- `src/unlocks.cpp` — постройки, открытые у хоста, открываются и у гостя
- `src/net.cpp` — TCP: поток приёма, кадры `[u32 размер][u8 тип][данные]` до 8 МБ
- `src/crash.cpp` — запись GML-стека в лог при падении
- `src/trace.cpp` — трассировщик для разработки: перехватывает функции из `coop_trace.txt`
  (рядом с `Forager.exe`, строки `имя<TAB>VA` как в `decompiled/code/index.tsv`) и пишет в лог цепочки GML-вызовов
- `src/log.cpp` — лог
- `third_party/minhook` — MinHook v1.3.4 (BSD-2)
