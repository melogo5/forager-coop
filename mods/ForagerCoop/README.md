# Forager Coop — Steam Workshop package

A Mod API mod (`ForagerCoop`) that installs the co-op by itself, without copying `version.dll` into the game
folder. Based on the Workshop integration for v0.1.2 by voidk 22 ([justberlim](https://github.com/justberlim) on GitHub, MIT).

## Build

The release workflow builds the package together with `version.dll` and attaches
`ForagerCoop-Workshop-<tag>.zip` to the release. Locally:

```powershell
powershell -File native\build.ps1
powershell -File mods\ForagerCoop\build.ps1 -Version v0.1.3   # -> mods\ForagerCoop\build\ForagerCoop-Workshop-v0.1.3.zip
```

## Uploading to Steam

Unpack the archive into `%LOCALAPPDATA%\Forager\mods\` (this gives `mods\ForagerCoop\`) and upload the mod from
the game's MODDING menu, or copy the files from `ForagerCoop\` into the SteamCMD content folder.

## How it works

- `Main.gml` (generated by `package.py` from `Main.gml.in`) embeds both DLLs. After COMPILE in MODDING it writes
  to `%LOCALAPPDATA%\Forager`: `ForagerCoop-<hash>.dll` (the co-op of this build), `catch_error.dll` (the
  `bridge.c` bridge, only once), `ForagerCoop-current.txt` (the DLL name for the bridge) and the
  `ForagerCoop-<hash>.ready` marker.
- On the next launch the game loads `catch_error.dll` from the profile folder. The bridge forwards calls to the
  game's original `catch_error.dll` and loads the DLL named in `ForagerCoop-current.txt`, if the mod is in
  `mods\ForagerCoop` or among the Workshop subscriptions and there is no `version.dll` next to `Forager.exe`
  (a manual install takes priority).
- A new version of the mod writes its DLL under a new name (the old one is loaded and locked) and switches
  `ForagerCoop-current.txt`; one more game restart is needed. Old `ForagerCoop-*.dll` files stay in the profile.
- The bridge stays loaded while the game runs, so it cannot be replaced by a newer bridge: a change to
  `bridge.c` needs a new marker name instead of `ForagerCoop-bridge-2.ready` and a way to update.

To disable: create `ForagerCoop-disabled.txt` in `%LOCALAPPDATA%\Forager`. To remove completely: delete
`catch_error.dll`, `ForagerCoop-*.dll`, `ForagerCoop-*.ready` and `ForagerCoop-current.txt` there.
