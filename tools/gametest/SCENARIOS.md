# Сценарии ручного тестирования (проверенные клики)

Координаты — клиентская область окна 1280×720, отправляются через `gamectl.ps1` (сообщения окну, реальная
мышь не нужна). Если сценарий пройден заново и что-то сдвинулось — поправь здесь.

```powershell
$ctl = 'Z:\repos\forager-coop\tools\gametest\gamectl.ps1'
& $ctl -GamePid <pid> -Click '641,60' -HoldMs 150   # клик
& $ctl -GamePid <pid> -Key Esc                      # клавиша (Enter, Esc, Back, T, ...)
& $ctl -GamePid <pid> -Text '/give stone 50'        # ввод текста
& $ctl -GamePid <pid> -Shot name                    # скриншот -> tools/gametest/shots/name.png
```

Логи: `Z:\SteamLibrary\steamapps\common\Forager\coop_native_<pid>.log`.
**Не трогать** нижний сейв в списке (настоящий мир пользователя, 65 уровень).

## 1. Запуск хоста и гостя

```powershell
& 'Z:\repos\forager-coop\tools\gametest\coopflow.ps1' -GodMode -GuestName 'Builder' [-HostSlotRow 1] `
    [-HostEnv @{...}] [-GuestEnv @{...}]
```
Печатает `HOST=<pid> GUEST=<pid>`. Внутри: главное меню → COOP (675,640) → у хоста CREATE (993,114) →
строка сейва (1000, 38+100·row); у гостя NAME (700,530) → Back×20 → имя → Enter → JOIN первого сервера
(995,205). Готово, когда в логе гостя `puppet: objPlayer`.

Чистый мир (так тестировать каждую новую фичу): удалить тестовые `saveData*` (кроме `saveData0` — настоящий
мир пользователя, 65 уровень) и запустить `coopflow.ps1 -NewWorld ...`: CREATE → «+» (под сейвами, y = 140 + 100 × число
сейвов) → Classic (165,370) → PLAY (650,575).

## 2. Выдать себе ресурсы (консоль)

`T` → `/give stone 50` → `Enter`. Работает и у гостя. Не копать руками.

## 3. Меню игрока

`Esc` открывает. Вкладки по y=60: GEAR x=457, ITEMS 549, BUILD 641, затем 733, 825.
- GEAR → SKILLS (540,172) — дерево навыков (выход — `Esc`; проверено два входа/выхода подряд).

## 4. Постройка через меню (проверено 2026-10-17)

1. Ресурсы: `/give stone 50` (печке хватает камня).
2. `Esc` → BUILD (641,60) → INDUSTRIAL (1135,58). Категории: INDUSTRIAL 58, FARMING 148,
   ECONOMIC 238, MAGICAL 328 (x=1135).
3. FURNACE (1135,128); FORGE 183, SEWING STATION 238.
4. Режим размещения: призрак идёт за курсором, **камера сдвигается за курсором** — после каждого клика
   кадр другой. Красный призрак = нельзя (вода, игроки). Кликать на траву рядом с игроком, затем делать
   скриншот и при необходимости повторять.
5. `Esc` — выход из режима размещения.

Ожидание: гость `sync: built object 109 at (x, y), sent to the host`, хост
`sync: guest built object 109 at (x, y) -> <id>`; печь видна на обоих экранах.

## 5. Общий сундук через интерфейс (проверено 2026-10-17)

1. Сундук без навыка: у **хоста** `T` → `/spawn objVault` → `Enter` — появляется рядом с хостом и через
   синхронизацию у гостя. (`/spawn` у гостя создаст только локальный сундук.) Есть ещё `/gml`, `/goto`,
   `/cheats` — см. `decompiled/code/scripts/ForagerCommandsInit.c`.
2. Навести курсор на сундук (клик без удержания: `-Click 'x,y' -HoldMs 0`) — появится подсказка **E**.
   Обычный клик бьёт сундук киркой. Камера едет за курсором, поэтому целиться ближе к центру экрана.
3. `E` — открыть. Сверху инвентарь (первая ячейка (90,190)), справа ячейки сундука (первая (930,195)).
   ЛКМ — переложить одну штуку (ПКМ — все, gamectl пока не умеет).
4. `Esc` — закрыть; содержимое уходит напарнику.

Ожидание: у закрывшего `storage: chest <id> (object 114) sent`, у напарника
`storage: chest <id> updated from the peer …, first cell: item 1 xN` (1 — камень). Пока сундук открыт у
одного, у другого `E` не открывает и в логе `storage: chest <id> is open by the other player`.

## 6. Выход гостя в меню и повторный вход (проверено 2026-10-19)

1. У гостя `Esc` → последняя вкладка (825,60) → **SAVE AND EXIT TO MENU** (930,505).
2. Через ~10 с главное меню: COOP (675,640) → JOIN (995,205).

Ожидание: гость `session: left the host's world; can join again`, затем снова `session: joining`,
`character: own character restored`, `puppet: objPlayer`; хост `session: peer gone`, затем
`net: guest connected`, снимок мира и новый `puppet: objPlayer`.

## 7. Вкладка BUY LAND (покупка островов)

`Esc` → (735,60). Таблички продажи (`objPurchaseLand`) существуют только пока вкладка открыта. Осторожно:
второй клик по вкладке может попасть по участку и купить его (так хост купил остров 2026-10-18).

## Готовые прогоны (2026-10-19)

- `regress.ps1` — **общая регрессия на чистом мире**: удары по врагам, постройка, сундук, крафт в инвентарь, общие
  монеты, прогресс, время суток; печатает PASS/FAIL. Перед запуском удалить тестовые сейвы (кроме `saveData0`).
- `culltest.ps1 [-Object 85] [-GuestName X]` — `COOP_DEBUG_CULLTEST`, печатает разницу списков объектов хоста и гостя
  в начале и в конце (пусто = совпали).
- `rejoin.ps1` — гость выходит в меню и снова JOIN; `hostleave.ps1` — хост выходит в меню (гость должен
  последовать), потом CREATE/JOIN заново. Печатают строки логов обеих сторон.
- `python -I cinder.py <файл.cin>` — распаковать сейв (`Zones/*.cin`, `Data.cin`) и посчитать объекты по именам.

## 8. Отладочные переменные окружения (через `-HostEnv` / `-GuestEnv`)

| Переменная | Что делает |
|---|---|
| `COOP_DEBUG_GODMODE=1` (`-GodMode`) | бессмертие |
| `COOP_DEBUG_AUTOHIT=1` | гость бьёт ближайшего врага раз в 2 с |
| `COOP_DEBUG_AUTOHIT=84` | …или ближайший объект с этим индексом (84 — камни) |
| `COOP_DEBUG_BUILD=<object>` | гость ставит постройку без меню (109 — печь) |
| `COOP_DEBUG_STORAGE=1` | гость открывает ближайший сундук, кладёт предмет #1 ×5, закрывает |
| `COOP_DEBUG_BUYLAND=1` | (хост) покупка острова ближайшей таблички через ~7 с; `=<секунды>` — позже. Таблички есть только при открытой вкладке BUY LAND (Esc → (735,60)) |
| `COOP_DEBUG_ENEMY=<object>` | хост спавнит врага рядом с гостем (26 — слайм) |
| `COOP_DEBUG_CLOCK=<таймер>` (хост) | хост один раз ставит свои часы суток; гость следует (`clock: light state` в логе гостя) |
| `COOP_DEBUG_UNLOCKS=1` (хост) | хост сообщает гостю, что открыты все постройки (сам хост не меняется; у гостя разблокировки сохранятся в персонаже) |
| `COOP_DEBUG_CRAFTDROP=<item>` (гость) | через ~5 с у гостя появляется дроп «как из крафта» — должен сразу оказаться в инвентаре |
| `COOP_DEBUG_COINS=<сумма>` (любой) | через ~5 с прибавляет монеты этой стороне, как заработанные (в новом мире для консоли нужен `-Cheats`) |
| `COOP_DEBUG_CHEATS=1` (`coopflow -Cheats`) | включает читы мира (`global.cheatsEnabled`) — в новом мире без них не работают `/give`, `/spawn` |
| `COOP_DEBUG_LANDFILL=1` (любой) | через ~5 с засыпает ближайшую воду; у напарника в логе `the peer's landfill ... water there now: 0` |
| `COOP_DEBUG_MUSEUM=<item>` (любой) | через ~5 с добавляет предмет в список музея; у напарника `progress: museum updated from the peer` |
| `COOP_DEBUG_QUEST=1\|<секунды>` (любой) | «трогает» первого NPC (NPCSetState + hasSpoken) через ~8 с или позже; у напарника `quests: NPC ... now` |
| `COOP_DEBUG_PROTOCOL=<n>` (любой) | сторона притворяется версией протокола n: у обоих окно-предупреждение (MessageBox, PrintWindow его не видит), игра продолжается |
| `COOP_DEBUG_STATION=<секунды>` (любой) | в это время открывает меню ближайшего станка (Other_11); у напарника станок становится занятым |
| `COOP_DEBUG_DUNGEON=1` (любой) | через ~5 с пытается войти в `rmAncientTomb` — должно быть отклонено (`not entering room 14`) |
| `COOP_DEBUG_XP=<n>` (хост) | раз в ~10 с даёт хосту n опыта: повышения уровня у обоих (`shared progress: level`, у гостя `skills: level N - K points earned`) |
| `COOP_DEBUG_SKILL=<n>` (любой) | через ~10 с отмечает навык n изученным, как покупка; у гостя он уходит хосту (`kept guest ... skills`) и возвращается после перезахода |
| `COOP_DEBUG_DESYNC=1` (оба) | через ~8 с хост тихо убирает у себя 3 ближайших к гостю объекта, гость — следующие 3: сверка (`reconcile:`) должна убрать у гостя лишние и вернуть недостающие за ~10 с |
| `COOP_DEBUG_CHEST=1` (любой) | через ~10 с открывает ближайший `objTreasureChest` (хост ставит его консолью `/spawn objTreasureChest`); у другой стороны копия убирается (`chests: the other player opened ... removed here`) |
| `COOP_DEBUG_CULLTEST=1` (обоим) | уничтожение объектов, усыплённых у гостя: обе стороны пишут в лог список камней, хост уничтожает дальние, обе пишут список снова — списки должны совпасть (`=85` — деревья) |
