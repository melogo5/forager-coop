# Кооп: состояние на 2026-10-18

Разработка продолжается (с 2026-10-18 — в этом репозитории). Ниже — что работает в `version.dll` и как
это проверено (две копии игры на
одном ПК; логи `coop_native_<pid>.log`, скриншоты; часть — вручную пользователем).

## Не сделано / известные проблемы

См. [QUESTIONS.md](QUESTIONS.md). Главное:

- **Иногда гость загружает мир, отличный от хоста** (лишние или недостающие деревья); стабильно не
  воспроизводится, подробности в QUESTIONS.md.

- **Запретить вход в подземелья** (или чтобы входы в них вообще не появлялись — что проще): в другие комнаты
  кооп пока не умеет, вход одного из игроков ломает сессию.
- Экран выбора режима при COOP → CREATE → «+» по-прежнему показывает все режимы (запрет — после старта мира).

## Для тестов

Отладочные переменные окружения: `COOP_DEBUG_GODMODE=1`, `COOP_DEBUG_ENEMY=<объект>`,
`COOP_DEBUG_CENSUS=1` (хост); `COOP_DEBUG_AUTOHIT=1|<объект>`, `COOP_DEBUG_BUILD=<объект>`,
`COOP_DEBUG_STORAGE=1` (гость); `COOP_DEBUG_BUYLAND=1`.
Запуск хоста и гостя — `tools/gametest/coopflow.ps1`; проверенные клики по меню —
[tools/gametest/SCENARIOS.md](../../tools/gametest/SCENARIOS.md); сравнение миров —
`tools/gametest/census-diff.ps1`.
