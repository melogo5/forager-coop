# Кооп: состояние на 2026-10-18

Разработка продолжается (с 2026-10-18 — в этом репозитории). Ниже — что работает в `version.dll` и как
это проверено (две копии игры на
одном ПК; логи `coop_native_<pid>.log`, скриншоты; часть — вручную пользователем).

## Работает

| Фича | Как проверено |
|---|---|
| Меню COOP: список серверов в сети (UDP 7791), CREATE (новый мир или сейв), JOIN, подключение по IP, поле NAME | хост найден автоматически, гость подключился; имя гостя введено в поле NAME |
| Мир хоста у гостя (снимок сейва во временный слот 99, после выхода он удаляется) | куст, сломанный хостом до подключения, отсутствует у гостя |
| Удары гостя применяет хост; опыт — гостю | куст +1 XP, слайм +6/+7 XP |
| Появление и уничтожение объектов мира | новые ресурсы появляются у гостя, сломанное исчезает у обоих |
| Добыча сразу в инвентарь тому, кто сломал/убил; чужую поднять нельзя | автодобыча гостя: камень и железо у гостя, у хоста не прибавилось |
| Мобы: позиции, анимация и здоровье с хоста; мир вокруг гостя у хоста не замирает | слайм двигается одинаково у обоих, гибнет от удара гостя |
| Полоски здоровья объектов у гостя | подтверждено пользователем |
| Смерть без game over: возрождение на стартовом острове | по 3 смерти у хоста и гостя, соединение не рвётся |
| Меню (Esc, инвентарь) не замораживает общий мир | слайм двигается при открытом меню хоста |
| Свой персонаж гостя (инвентарь, уровень, навыки), хранится у хоста по имени, выгружается раз в 15 с | новый гость — 0/80 XP при 65/80 у хоста; при повторном входе восстановлен |
| Постройки гостя появляются у хоста | печь через меню BUILD; печь и сундук отладочной постройкой |
| Общие сундуки: открыт только у одного, содержимое уходит при закрытии | через интерфейс: гость положил камень ×3 — у хоста ×3; хост взял один — у гостя ×2 |
| Покупка острова (только хост) — у гостя появляется тот же остров | подтверждено пользователем |
| Гость уходит в дерево навыков и возвращается | два входа/выхода подряд без ошибок |
| Сообщения до 8 МБ (большие сейвы и персонажи) | — |
| Хост выходит в меню: гость получает «сессия окончена» и сам уходит в главное меню (как после game over); оба могут начать заново (CREATE / JOIN) | хост «Save and exit to menu» → гость в меню через ~15 с; затем хост CREATE, гость JOIN — мир получен, напарник создан, без ошибок |
| Хост пропал (упал, оборвалась связь): через ~5 с без связи гость сам уходит в главное меню | процесс хоста убит — гость `the host is gone`, в меню через ~15 с, без ошибок |
| Повторный вход без перезапуска: гость выходит в главное меню (сессия у него сбрасывается, хост видит уход) и снова JOIN | выход через «Save and exit to menu» → COOP → JOIN: мир и персонаж получены заново, мобы/объекты/часы синхронизируются, без ошибок |
| Инструмент в руках напарника: передаётся номер предмета (`ToolSelected()`), у напарника — свой список-тулбар с этим предметом | на скриншоте хоста напарник с киркой; после двух заходов гостя в дерево навыков — по-прежнему, без ошибок (прежняя попытка с передачей id списка роняла отрисовку) |
| Враги у гостя — ровно те, что присылает хост (чужие локальные враги и брошенные реплики удаляются) | автоудар гостя: 40 ударов применены на хосте, 7 врагов убиты, опыт гостю; при входе удалено 20 «призраков» |
| Постройки, открытые навыками хоста, открыты и гостю (`StructureGet(s, 11)` → `StructureEdit(s, 11, true)`, раз в 5 с; закрытыми не делаются) | `COOP_DEBUG_UNLOCKS=1` у хоста: гостю открыто 85 новых построек из 92, в BUILD → INDUSTRIAL вместо «???????» видны Mining Rod … Ballista. Тестовый персонаж `Builder` после этого хранит все разблокировки |
| Крафт: готовое сразу в инвентарь тому, кто крафтил (у хоста — весь его дроп и так; у гостя — дроп из `HandleCrafting` подбирается на следующем шаге, хосту не сообщается) | `COOP_DEBUG_CRAFTDROP=1` у гостя: предмет в инвентаре, хосту ничего не ушло |
| Общий опыт и уровень у хоста: опыт за действия гостя начисляется хосту, опыт, заработанный у гостя, пересылается хосту; гость видит уровень/опыт/очки навыков хоста. Навыки у гостя не покупаются (шаг `objSkill` выключен) | новый мир: гость бьёт камни — у обоих «LEVEL 1 [9/80]» |
| Время суток и погода — с хоста (раз в секунду: таймер суток, фаза света, таймеры дождя/снега/дыма/пыли) | `COOP_DEBUG_CLOCK=40000`: хост перевёл часы — у гостя фаза 2 → 3 (ночь) в ту же секунду, ночь на скриншоте, без ошибок |
| Уничтожение объектов, которые у гостя вне экрана (усыплены игрой) | `COOP_DEBUG_CULLTEST`: хост уничтожил 45 дальних камней — списки камней у обоих совпали (3 = 3); без исправления на деревьях 20 у хоста против 71 у гостя |

## Не сделано / известные проблемы

См. [QUESTIONS.md](QUESTIONS.md). Главное:

- **Иногда гость загружает мир, отличный от хоста** (лишние или недостающие деревья); стабильно не
  воспроизводится, подробности в QUESTIONS.md.

- Подземелья и другие комнаты.
- **Создавать COOP-мир можно только в режиме Classic** (остальные режимы — позже): в экране выбора режима
  после CREATE → «+» оставить только Classic.

## Для тестов

Отладочные переменные окружения: `COOP_DEBUG_GODMODE=1`, `COOP_DEBUG_ENEMY=<объект>`,
`COOP_DEBUG_CENSUS=1` (хост); `COOP_DEBUG_AUTOHIT=1|<объект>`, `COOP_DEBUG_BUILD=<объект>`,
`COOP_DEBUG_STORAGE=1` (гость); `COOP_DEBUG_BUYLAND=1`.
Запуск хоста и гостя — `tools/gametest/coopflow.ps1`; проверенные клики по меню —
[tools/gametest/SCENARIOS.md](../../tools/gametest/SCENARIOS.md); сравнение миров —
`tools/gametest/census-diff.ps1`.
