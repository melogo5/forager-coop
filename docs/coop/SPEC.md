# Forager Coop — спецификация v1

Нативный кооп до 4 игроков через DLL-патч (`version.dll` рядом с `Forager.exe`), билд игры 2.2.2.302.
Согласовано 2026-10-16. Как реализуем — [ARCHITECTURE.md](ARCHITECTURE.md); код и сборка — [native/README.md](../../native/README.md).

## Сессия

- До 4 игроков: **хост** и до трёх **гостей** (с 2026-10-20, [MULTIPLAYER.md](MULTIPLAYER.md)). Сеть — локальная: LAN, Hamachi или Radmin.
- Мир существует только у хоста. Без запущенного сейва хоста играть в этот мир нельзя.

### Меню «Кооп»

- В главном меню игры новый пункт **«Кооп»**.
- Экран «Кооп» сразу показывает **список серверов в локальной сети**, найденных автоматически
  (имя хоста, мир, игроков 1/4). Выбор сервера → подключение → гость попадает в мир хоста.
- Кнопка **«Создать»** сверху: выбрать **новый мир** или **существующий сейв** → мир загружается,
  сервер запускается и появляется в списке «Кооп» у других игроков.
- У гостя от подключения не остаётся сейва в обычном списке: мир хоста загружается во временный слот.
- Если сервер не найден автоматически — запасное поле «Подключиться по IP».
- Моды Forager mod API не поддерживаются (считаем, что их нет).

## Что общее, что своё

| Своё у каждого игрока | Общее (мир хоста) |
|---|---|
| Монеты | Острова (покупать может любой игрок, за свои монеты) |
| Уровень, XP, навыки | Постройки, сундуки (общий доступ) |
| Инвентарь, снаряжение, инструменты | Ресурсы, мобы, дроп на земле |
| Здоровье, выносливость (энергия) | Время суток, погода |
| Дроиды (добыча идёт владельцу) | Достижения, задания NPC, музей, глобальный прогресс |

- Навык, открывающий постройку или контент мира, считается открытым, если он есть хотя бы у одного игрока.
- Персонаж гостя хранится **у хоста**, отдельно от основного сейва, с привязкой к гостю.
- Достижения Steam получает только хост.

## Мир и передвижение

- Каждый ходит где угодно. Хост держит активными объекты вокруг обоих игроков.
- Хост — единственный источник правды о мире: спавн, урон по объектам, дроп, постройки, сундуки.
- Свои действия (удар, подбор предметов) гость видит сразу, хост затем подтверждает или поправляет результат.
- Пауза при открытом меню или инвентаре в коопе отключена: мир продолжает работать.

## Зоны (данжи, боссы, пазлы, Void)

- В v1 не реализуются, но в архитектуре для них есть место.
- Зона одна на всю игру (`global.zoneCurrent`). Переход в зону выполняет хост, оба игрока переносятся вместе.

## Смерть

- Ни у хоста, ни у гостя нет game over и выхода в меню.
- Игрок возрождается на центральном стартовом острове с полным здоровьем. Штрафа нет.

## Вне v1

- Подключение через Steam, совместимость с модами, данжи и боссы.
