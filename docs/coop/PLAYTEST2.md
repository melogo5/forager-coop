## Дерево навыков в мире (#2) — где остановились

`native/src/skilltab.cpp`, включается `COOP_INWORLD_SKILLTREE=1` (по умолчанию — старое меню-комната):
- переход в `rmSkillGrid` в сессии перехватывается (`room_goto`), вместо него в комнате мира создаётся
  `objSkillGridControl` (он сам делает 64 `objSkill`); при его создании `room_width/height` подменяются на 1280×720;
- загрузка игрока из сейва, которую делает дерево (`LoadAsync` → `LoadPlayer`, она же ставит `skillDisplay`),
  в мире пропускается (вернула бы сохранённое состояние поверх живого), `skillDisplay` ставится сразу;
- аватар игрока, которого дерево создаёт для своей комнаты, — «инертный» (`puppet::SetInert`, невидим), иначе это
  второй игрок в мире (его шаг выдавал игровое окно «you are really stuck»);
- дерево рисуется в GUI-слое поверх мира (свой проход в `Draw_64` дерева: навыки по глубине, матрица масштаба),
  `mouse_x/y` для его кода — координаты мыши в GUI;
- свой игрок стоит (его `Step_0` не выполняется, `puppet::HoldLocalPlayer`), мир идёт; выход (`room_goto(rmGame)`)
  убирает дерево.

Работает: дерево видно поверх живого мира, «SKILL POINTS», подсказки, выход. **Не работает**: навыки мелкие и без
подсказок при наведении, покупка (удержание мыши на навыке) не срабатывает — вероятно, наведение у навыка проверяется
не только по `mouse_x/y`. Следующий шаг — разобрать `objSkill/Step_0` вокруг `mouse_check_button` (строки
~3979–4875 в `.c`) и `instance_position` у `objSkillGridControl`.

Тестовые переменные: `COOP_DEBUG_SKILLTREE=<с>` (открыть через столько секунд и закрыть через 10 с).
