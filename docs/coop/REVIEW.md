## Осталось

- **Токен/код подключения.** Рукопожатие отсекает чужие программы, но не чужой экземпляр мода в той же сети. Нужен ли
  код комнаты (и как его показывать в LAN-списке) — решение за пользователем.
- **Отказ при другой версии протокола** вместо предупреждения — сейчас сознательно не сделан (STATUS.md: проверено и
  оставлено предупреждение).
- `sync.cpp` всё ещё ~1275 строк: дальше делить по областям (дропы, удары, реплики).
- `ForgetInstance` (`mobs.cpp`) на каждое уничтожение — не трогал: пропускать «никогда не спавшие» объекты рискованно
  (игра держит в списках клеток и проснувшиеся), цена не измерена.
- Хранилище: если гость скрафтил из сундука, пока его держит открытым другой, расход крафта перезапишется содержимым
  закрывающего (нужно слияние, не только блокировка).
- `fishing.cpp` — намеренный лог для открытой ошибки PLAYTEST2 #6, оставлен.
- Проверить вживую: отмену CREATE (выход из экрана сейвов), предупреждение о занятом порте, ловушку двумя людьми.
